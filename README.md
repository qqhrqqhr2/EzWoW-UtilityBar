# EzWoW-UtilityBar

## English

**Consumables and utility spell action bar** for WoW Forever (Interface 16001).

- Install the `EzWoW-UtilityBar` addon folder under `Interface/AddOns/`.
- The complete source distribution includes detailed features, settings, changelog and license information.
- In-game compatibility still requires testing.

## 한국어

WoW Forever(Interface 16001)용 **소모품 및 편의 주문 액션 바** 애드온입니다.

- `EzWoW-UtilityBar` 폴더를 `Interface/AddOns/`에 설치하세요.
- 전체 소스 패키지에 상세 기능 설명, 설정, 변경 이력 및 라이선스가 포함되어 있습니다.
